# Modelo Secuencial Simple con TensorFlow.js

Este proyecto consiste en una implementación básica de un modelo de aprendizaje automático utilizando TensorFlow.js, que aprende la fórmula: **Y= 2x+6**.

## ¿Qué hace?

1. Entrena un modelo secuencial en el navegador con 9 muestras (valores de x desde -6 a 2).
2. Una vez entrenado, el modelo queda listo para hacer predicciones.
3. El usuario puede ingresar un número (x), y el sistema le mostrará el valor estimado de y.

## Tecnologías utilizadas

- HTML5
- JavaScript (vanilla)
- [TensorFlow.js](https://www.tensorflow.org/js)

## ¿Cómo usarlo?

1. Abrí el archivo `index.html` en tu navegador.
2. . Ingresá un valor para `x` en el campo de texto.
3. . Hacé clic en “Predecir Y” y verás el resultado estimado de `y`.
